# 🍽️ La Notte — Landing Page de Restaurante

Landing page completa para un restaurante de alta cocina italiana.
Proyecto de portafolio freelance desarrollado con HTML5, CSS3 y JavaScript vanilla.

## 📁 Estructura del proyecto

```
restaurante-la-notte/
├── index.html          ← Página principal
├── css/
│   └── styles.css      ← Todos los estilos y animaciones
├── js/
│   └── main.js         ← Lógica e interacciones
└── README.md           ← Este archivo
```

## 🚀 Cómo usar

1. Clona el repositorio:
   ```bash
   git clone https://github.com/srguss77/restaurante-la-notte.git
   ```
2. Abre `index.html` en tu navegador.
3. No requiere instalación ni dependencias externas.

## ✨ Características

- Diseño elegante de tema oscuro con detalles dorados
- Hero con imagen de fondo y animación de zoom suave
- Menú con 5 categorías navegables por pestañas (Entradas, Pastas, Platos, Postres, Vinos)
- Galería fotográfica con efecto hover
- Sección de testimonios de clientes
- Formulario de reservas funcional con validación
- Scroll reveal: los elementos aparecen con animación al hacer scroll
- Navbar transparente que cambia de estilo al bajar
- Menú hamburguesa para pantallas pequeñas
- 100% responsivo (móvil, tablet y escritorio)

## 🛠️ Tecnologías usadas

| Tecnología  | Uso                               |
|-------------|-----------------------------------|

| CSS3        | Estilos, animaciones, responsive  |
| JavaScript  | Tabs, formulario, scroll reveal   |
